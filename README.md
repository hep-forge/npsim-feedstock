Feedstock for [npsim](https://github.com/eic/npsim) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

DD4hep-based simulation plugins, front-end, and related utilities

## Architectures

| Architecture | Latest published |
|--------------|------------------|
| linux-amd64 (`linux-64`) | ✅ `1.6.1` |
| linux-arm64 (`linux-aarch64`) | ✅ `1.6.1` |

_As of the last feedstock render; the badges above are live._


## Install

```bash
conda install -c hep-forge -c conda-forge npsim
```
